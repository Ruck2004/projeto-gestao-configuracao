# Controle de Tarefas da Equipe

Projeto didático em Python para demonstrar o gerenciamento de artefatos de software com Git.

## Objetivo

Manter uma lista simples de tarefas de uma equipe de desenvolvimento e demonstrar como arquivos do projeto podem ser versionados.

## Estrutura inicial

- `app.py`: aplicação de linha de comando.
- `tarefas.csv`: dados de exemplo.

## Execução

```bash
python app.py
```

## Atualização da atividade prática

Foi incluída a contagem de tarefas não concluídas na aplicação e criado o arquivo `relatorio.py`, que apresenta um resumo por status. As alterações foram registradas em commit separado para manter a rastreabilidade.
